# =============================================================================
# Harsh Winter - which game textures each season pack changes
#
#   <group>  <pattern>
#
# Patterns are globs (* = anything) on the lower-case path of a file inside the
# game's .pak archives. Files in level paks are seen as levels/<level>/<path>.
# The FIRST matching line decides a texture's group; "exclude" lines always win.
# Run "Build texture packs.bat list" to see what every pattern matches before
# building, and add or remove lines here to taste. Nothing needs recompiling.
#
# Groups and what the packs do to them:
#   terrain     ground layers           snow: deep snow      thaw: snow patches + mud
#   road        roads and paths         snow: trodden snow   thaw: deep mud
#   roof        roofs, thatch, hay      snow: heavy snow     thaw: melting patches
#   rock        rocks and cliffs        snow: dusting        thaw: wet
#   props       fences, carts, barrels  snow: hoar frost     (textures can't put snow only on top faces)
#   glass       window glass            snow: frost
#   conifer     pines, spruces, firs    snow: snow on top of every needle spray and needle layer
#   deciduous   broadleaf trees, bushes snow: bare - every leaf removed, whatever its colour
#               (green, yellow, orange, red) - with snow along the top of the twigs
#               and branches and in the forks; frosted bark
#   (marcescent is accepted as an old name for deciduous)
#   grass       grass, herbs, ferns     snow: mostly buried, straw tips with frost
#   billboard   distant tree impostors  snow: snowy dark conifers, bare grey-brown crowns
#   cover       distant terrain map     snow: white landscape to the horizon
#   panorama    the far landscape painted on horizon meshes (objects/panorama/...)
#               snow: open land under deep snow, woods dark and dusted white
#   snowdirt    people's dirt/grime     snow: the dirt on clothes becomes powder snow
#   mtl-terrain / mtl-road: material files; their diffuse textures join terrain / road
#   interior-mtl  material files of interiors: every texture they use stays
#                 snow-free (floors, inner walls, furniture, the inside of roofs),
#                 even if outdoor objects share it. Terrain and road layers keep
#                 their snow (they're the landscape).
#
# After every build, Mods\harsh_winter_world\build_report.txt lists what got
# snow, what was kept snow-free, and textures whose NAMES suggest ground, road
# or roof but that no rule caught - add a line here for those and rebuild.
# =============================================================================
