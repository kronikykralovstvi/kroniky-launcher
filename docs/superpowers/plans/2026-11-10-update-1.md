# Update 1 — synchronizace a stabilita

> **For agentic workers:** Use superpowers:executing-plans, implement in this session.

**Goal:** Aktualizovat oficiální klient KCD:MP z našeho launcheru, připojit aktuální web a opravit serverové transakce bez ztráty dat.

**Architecture:** Oficiální klient má oddělenou verzovanou instalaci. Archiv pochází pouze z oficiálního GitHub repozitáře, kontroluje se SHA-256 a rozbalení. Vlastní mody dál používají existující podepsané vydání. Produkční data nejsou součástí aktualizačních archivů.

**Tech Stack:** C# .NET 10 WinForms, PHP Endora, Lua KCD:MP.

**Spec:** Požadavek uživatele 10. 11. 2026 v tomto chatu; první update zahrnuje launcher, web, server, optimalizaci a ověření mechanik.

## Global Constraints
- Zachovat herní data, stávající funkce a podpisové ověřování.
- Server nyní běží na 0.49.1; žádné přepisování používaného gamemode.
- Nepovažovat rozdílné klientské/serverové patch verze za chybu.
- Předchozí oprava nákupů není potvrzená, nesmí být označena za hotovou.

## Review Focus
- Server-only release nesmí skrýt poslední klientský archiv.

- Čekání na transakci nesmí navždy zadržet ovládání nebo přidat odměnu dvakrát.
